# P2 五字载体衔接校准

2026-11-20。沿用第二张任务卡的 20 篇研究摘要、已入选的 GB18030 流和每篇封装 E，只改变五字句池的衔接规则。各轮使用同一份逐篇正文流，保留五字、交替逗号和句号及每四句换行。每篇每个实测规则随机加密一次，独立主机进程从配置、公开夹具密钥和完整成品认证回读。[任务卡结论](p2-plan.md#第二张任务卡结论) · [固定封装来源](p2-gb-calibration.md)

## 容量筛选与实测

按 `L=floor((4*5*S+4)/73)` 反推每篇的最多五字句数。研究摘要和小说所需的第 10 小平均容量分别为 15.17 和 17.83 位／句。全库 213,300 句独立任选的极限约为 17.70 位／句，按固定封装分别最多容纳 19/20 与 9/20。实际收发使用研究摘要。

用 P1 锁定的五字库建立候选。扩展规则的首句可任选含 79 个意象字之一的句子。随后取上一句从右往左第一个意象字，通过该字或其所属类别选择下一句。三类顺序为天时、水景、山林，类别循环相接。[P1 锁定五字库](p1.md#公开配置和研究模式草案)

## 校准试读材料

宽规则实测 11/20，达到 10/20 的校准排期门槛。选取全部 11 份达标成品做试读。每篇抽取一份使用同一主题规则、逐篇等句数、等 UTF-8 长度和同版式的普通集句作为对照。22 份材料匿名打乱，读者评分表与主持人答案分别存放。本批成品 373–536 句，现有四句人作摘样不满足这一篇幅，试读包缺少同篇幅人作对照。评分项为相邻句衔接、整篇连贯和是否愿意读完，尚无读者评分。60 篇留出仍封存，尝试数为零。

## 复现与验证

在仓库根运行。使用冻结的 P1 配置及已构建的 AES 帮助程序，正文直接复用校准报告指定的 GB18030 模式。[P1 构建](p1.md#运行-p1) · [第二轮字典资产与输入](p2-gb-calibration.md#复现)

```powershell
$root = '.tmp-evidence/themed-verse-p2-corpus-20261120'
$profile = '.tmp-evidence/themed-verse-p1-20261120/profile'
$out = Join-Path $root ('theme-rerun-' + [guid]::NewGuid())
$lock = 'e2c4aeaa4daf6f17e2fa2d1a6871f9183cc58a008a34fd9ea50edc1c94a17652'
$gbResult = '282ae71b5740218ba21645e7cdeb25d8e6dd508b2b0683ecabbb2cdf91568ea2'
python -B tools/themed-verse/p2_theme_trial.py run "$profile" "$root/calibration-input" "$root/calibration-independent" "$root/calibration-gb-finished" "$out" --lock-sha256 "$lock" --gb-results-sha256 "$gbResult"
python -B tools/themed-verse/p2_theme_reading.py "$out" "$out/blind"
```

完成轮位于上述目录的 `calibration-theme`。机器记录为 `results.json`，每个规则子目录保存成品与相应的新规则资源。读者使用 `blind/readers/scores.md`，主持人答案为相邻目录的 `blind/organizer.json`。新规则各自绑定其资源摘要。
