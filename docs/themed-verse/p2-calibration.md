# P2 新语料冻结与校准

2026-11-20。校准使用冻结的 P1 正文编码、单层 AES 主机封装和集句正文。20% 按完整成品 UTF-8 长度 `V <= 5*S` 逐条判定，并执行 8,192 UTF-16 单元和 16,384 B 两项硬上限。每类分母包含全部校准尝试。[任务卡](p2-plan.md#下一会话第一张任务卡)

工作记录取已公开的研究工作摘要。考試院資訊處 2026 年取得的《考試院委託研究報告》快照入选 38 篇，內政部建築研究所 2026 年取得的《內政部建築研究所全球資訊網_研究成果》快照入选 25 篇，國家發展委員會人力發展處 2026 年取得的《人力供需議題相關研究報告》快照入选 3 篇。各发布机构依政府资料开放授权条款第 1 版释出数据。逐篇标注原机构、报告、署名者、来源和采用的摘要字段，快照版由清单内的 SHA-256 区分。[考試院资料](https://data.gov.tw/dataset/158138) · [建築研究所资料](https://data.gov.tw/dataset/25125) · [國家發展委員會资料](https://data.gov.tw/dataset/55806) · [开放授权条款](https://data.gov.tw/license)

自由叙事取 Project Gutenberg 官方镜像中 66 位署名作者的中文古典及早期现代小说。逐篇登记书目、下载地址、镜像字节摘要和支持原作年代的作者或作品分类。候选排除了关联续书、已知重编合集和书目与正文不一致的版本。截取从章回或故事正文起，保留其中的引诗、说书式评议、繁简字及标点。[官方镜像说明](https://www.gutenberg.org/help/mirroring.html) · [书目快照来源](https://gutenberg.pglaf.org/cache/epub/feeds/pg_catalog.csv) · [文本使用条件](https://www.gutenberg.org/policy/license.html)

候选正文清理可见表现之外的 HTML、电子书页眉页脚和外侧空白。换行统一为 LF。所有输入固定取 2,048 B 内最长的完整 UTF-8 字符前缀，少于 1,024 B 的剔除。每篇来源、正文定位、输入字节数和 SHA-256 见清单。每位署名作者只出现于一个作品，联合署名整体参与排重。候选按固定种子和来源 ID 的摘要排序后分配 16／20／30，分配先于任何容量实验。

全库 132 个作品簇、171 个标准化署名身份。33 个被考虑的候选因作者或作品簇重合被排除。所选样本的 8,646 个文档对按去空白和标点后的 NFKC 比较文本检查精确重复、共有 48 字连续串和 7 字片段 Jaccard ≥0.20，均未命中。规范化仅用于重复检查，喂给 P1 的是已锁定的原始 UTF-8。[语料锁](p2-corpus-lock.json)

## 复现

本机工作目录为 `.tmp-evidence/themed-verse-p2-corpus-20261120`，随目录保留原始公开快照和镜像文件。已冻结快照见其 `frozen-final` 子目录。校准进程的输入目录只有清单、训练包和校准包，60 篇留出原文独立位于 `frozen-final/sealed/holdout.zip`。评测读入器只提供训练和校准。独立接收进程的目录只有主机程序、公开配置与夹具输入。

在仓库根复现，`$profile` 指向已冻结的 P1 配置目录，配置摘要为 `151099ba9459617e0f3af72543fb876f8653ef3ae984b6d1218a2b8f361e33db`。按既有命令准备 P1 的 Rust 帮助程序。[P1 构建](p1.md#运行-p1)

```powershell
$root = '.tmp-evidence/themed-verse-p2-corpus-20261120'
$profile = '.tmp-evidence/themed-verse-p1-20261120/profile'
$lock = 'e2c4aeaa4daf6f17e2fa2d1a6871f9183cc58a008a34fd9ea50edc1c94a17652'
$out = Join-Path $root ("p1-rerun-" + [guid]::NewGuid())
python -B tools/themed-verse/p2_calibration.py run "$profile" "$root/calibration-input" "$out" --lock-sha256 "$lock"
```

如需从原始快照重做冻结，输出目录使用新名称。快照中的 `pg-texts/titles.json` 记录了本次审核的镜像文件及书目行，书目 CSV 来自镜像的离线目录。

```powershell
$rebuild = Join-Path $root ("freeze-rerun-" + [guid]::NewGuid())
python -B tools/themed-verse/prepare_p2_sources.py "$root/inputs" "$rebuild/candidates"
python -B tools/themed-verse/p2_corpus.py "$rebuild/candidates/index.json" "$rebuild/frozen"
```

## 冻结 P1 的校准结果

| 体裁 | 逐字节恢复 | 达到 20% | 整条硬上限内 | 普通草稿上限内 | 超目标长度范围 |
|---|---:|---:|---:|---:|---:|
| 工作记录 | 20/20，37,680 B | 0/20 | 20/20 | 0/20 | 981–3,384 B |
| 自由叙事 | 20/20，40,942 B | 0/20 | 20/20 | 0/20 | 1,969–4,766 B |

每篇只随机加密一次，独立接收进程核对全部字节。工作记录中 GB 字典入选 14 次、RMW 5 次、UTF-8 字典 1 次。自由叙事中 RMW 入选 13 次、GB 字典 7 次。最佳利用率分别为 17.76% 和 16.77%。所有未过线样本的成品均完成认证与恢复，原因均为 `below-20`。

位置字典流为该候选实际流长。最终模式优先取最小封装档，同档按 P1 固定次序。表中长度均为 B，UTF-16 一列为代码单元数。逐篇作者、作品与正文摘要由样本 ID 对照语料锁。机器记录另含分阶段耗时、候选排除原因和整条计数。[语料锁](p2-corpus-lock.json)

每篇封装上界按最宽松的衔接计算。取满足 `18*L + floor((L-1)/4) <= 5*S` 的最大五字行数 `L`，再以主题首池 30,908 句、后续每池最多 12,833 句推算 `2^(8*E) <= 30908*12833^(L-1)` 允许的最高 64 B 档。即使采用这一上界，工作记录也全部超出 2–5 档，自由叙事全部超出 3–7 档。实际衔接池变小可能进一步降低可用容量。
