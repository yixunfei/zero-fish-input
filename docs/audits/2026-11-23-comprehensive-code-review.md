# ZeroInput 全量代码审查复核

复核日期为 2026-11-23。以仓库源码、调用链、现有测试和项目 ADR 为依据逐项复核原报告的 33 项反馈。其中 20 条反馈成立，合并重复的任务生命周期反馈后共 19 项。下表保留原编号，便于追溯。

| 原编号 | 确认的问题 | 修复 |
| --- | --- | --- |
| BUG-02、BUG-16 | 前台任务按设计在 Activity 销毁时撤销。配置重建会丢失中断反馈，包括潜在写入已发出的情况。SAF 回执随旧 owner 失效，任务随销毁撤销。 | 重建时显示通用停止或写入结果不确定的状态。任务、审批和 URI 继续随旧 owner 失效。 |
| BUG-04 | 控制器的停止代次与协调器代次相互独立。协调器在并发提交时分开更新代次和读取当前句柄，较旧的提交可能取消较新的句柄。 | 原子更新代次与交换句柄，取消已失效的请求并屏蔽其回调。 |
| BUG-05 | Responses 的完成事件包含完整输出。合规答案可在输出仍符合 32,768 字符上限时超出 16,384 字符的 SSE 行或事件上限。 | 为 Responses 单独设置有界事件上限，保留总流量及输出上限。 |
| BUG-06 | MCP Streamable HTTP 接受在 RPC 响应前发送通知或请求。客户端在第一个数据事件停止，导致合法响应尚未读取就判定失败。 | 跳过无关报文，找到匹配 ID 的响应后停止读取。 |
| BUG-12 | 安装中断后遗留无安装标记的目标目录，下一次安装仍尝试直接用 staging 覆盖非空目录。 | 在激活前清理不完整的目标目录，清理失败时停止并允许下一次尝试。 |
| BUG-13 | 一个独立草稿损坏、消失或无法解密时，已认证的安全剪贴板管理页无法列出其余健康条目，也无法从列表删除受影响条目。 | 保留受影响条目的 opaque ID、时间和独立删除入口，显示内容不可用。 |
| BUG-14 | 输入视图恢复时，应用中文配置可能清掉已就绪的引擎，却没有在该入口重新调度预热。 | 通过会话预热入口应用配置并准备新引擎。 |
| BUG-15 | 表情搜索草稿使用默认中文选项，简繁、模糊音等与当前会话不同。 | 继承会话选项，并匹配搜索面板固定的全键盘、全拼设置。 |
| BUG-17 | 运行时前置检查拒绝启动后，工具任务页无条件清除已选文件、工具、工作上下文和通知选项。 | 运行时接管后再清除设置及转移资源所有权。 |
| BUG-18 | 直接提交字面文本、成对符号和引擎未处理的字符时，拒绝结果未进入编辑器反馈。 | 显示通用提交结果提示，避免缓存或自动重发直提内容。 |
| BUG-21 | 草稿处理动作后仅凭组合为空便清除长度上限状态，未区分提交是否仍被拒绝。 | 提交失败解除后才复位长度上限提示。 |
| BUG-22 | 形码相似字查询失败后，选中的种子仍阻止继续输入。 | 退回可继续编辑与重试的种子列表。 |
| BUG-23 | 用户词库页退出时仅依赖清空搜索文字触发分页复位。空搜索翻页后返回可能仍在原页。 | 退出时显式清零分页。 |
| BUG-24 | 触摸已将拼读说明后缀映射到原始输入末尾。无障碍设置选区仍使用仅覆盖可编辑前缀的偏移表，导致后缀边界被拒绝。 | 让触摸和无障碍使用同一完整映射。 |
| BUG-27 | 模型发现拒绝合法的空目录，设置界面因此显示解析错误。 | 交给设置界面已有的空目录状态处理。 |
| BUG-28 | MCP 成功响应的空 `content` 数组被当作执行失败。 | 将空数组处理为成功且无文本输出，保留错误和非文本校验。 |
| BUG-29 | 隐写口令的输入限制以 UTF-16 长度计算，密码运算以 UTF-8 字节计算。非 ASCII 口令可能到后台才因超限被拒绝。 | 输入时按 UTF-8 字节检查，并使用长度或无效字符提示。 |
| BUG-30 | 隐写任务返回时，上下文失效可能留下已关闭的待处理操作，定时清理还会把上下文失效显示为超时。 | 立即清理当前失效操作，仅在确实到达期限时提示超时。 |
| BUG-31 | 词库成功清除后，仓库状态仍报告清除前的写入失败。 | 清除成功时重置该状态。 |

复核协议行为时参考了 [Anthropic Messages](https://platform.claude.com/docs/en/api/messages/create)、[OpenAI Responses 流式事件](https://developers.openai.com/api/reference/resources/responses/streaming-events#response-completed)、[MCP Streamable HTTP](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)、[MCP Schema](https://modelcontextprotocol.io/specification/2025-11-25/schema)。
