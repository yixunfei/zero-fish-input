# 隐写安全与体验反馈核查及修复

日期：2026-11-19。依据：[原报告](2026-11-19-stego-security-ux-audit.md)、当前工作区源码、ADR 0039 和本轮验证。

用户确认采用推荐范围：修复证据明确的缺陷，优化提醒及可访问性；保留导航、选区变化、重新编辑时的清除边界，不增加密钥导出或密钥文件往返保留载文。
原工作区已有大量未提交修改，本轮在其基础上修改，不回退、不提交、不清理原有内容。

## 安全项

| 编号 | 核查判断 | 处理 |
| --- | --- | --- |
| S1 | 确认缺陷。WORKING 沿用旧 EDITING 截止时间 | begin 成功后给独立 120 秒处理预算；到期编辑不得复活；预览/结果仍仅 30 秒。prepare 入口续编辑预算 |
| S2 | 秘密正文确认缺陷；公开文本例子描述不准确 | 键入、替换、导入共用严格 UTF-8 字节预算，不截断；超限及无法提交的组合都有专门反馈。512 个 UTF-16 单元最多 1536 字节，报告举例再加 ASCII 已先超字符限制 |
| S3 | 存在生命周期回调内部短窗口，非已证明的跨会话泄露 | 原实现已有原子 valid 和操作租约，关闭/设置变更会撤销；IME 结束视图/会话改为首先撤销，worker 补删除代次校验。仍在主线程检查完整前台资格后发起、回调再检查；worker 不读 View/会话对象。Android 实际窗口变化与回调之间不具有原子保证 |
| S4 | 确认缺陷，入队失败仍报成功；复核发现全局关闭及删除代次变化的交接竞态 | offerPaste 返回是否接收，拒绝立即清零；调用方只在成功入队时显示已读取。交接显式携带读取时捕获的删除代次，不重新标记为最新代次；入队/取用/可用性均检查全局开关 |
| S5 | 确认可用性缺陷；原上限本身属于安全设计 | 开始认证时设置独立 30 秒预算，与既有 broker 一致；成功后另有 30 秒确认；取消返回 120 秒编辑预算；超时使用专门文案 |
| S6 | 确认状态缺陷 | 认证回调立即清 detour；等待窗口焦点只使用 authorizedSave。认证结束后离开页面会清除请求 |
| S7 | 确认可优化分配，非可利用漏洞 | 隐写 LocalDraftInput 不再向未使用的渲染参数复制全文；隐藏字段直接使用长度，UTF-8 计数不生成字节或字符串副本。显式显示、引擎和平台仍可能产生不可擦除 String |
| S8 | 属于验收缺口，非生产漏洞结论 | 增加门控截止、中文/emoji 字节上限、凭据/清空与菜单回归；平台结果及残余矩阵见下文。不把跳过、历史结果或静态审查计为本轮通过 |

原报告未发现直接泄露漏洞，本轮也不将这些体验或状态问题升级描述为已可利用的安全漏洞。
ADR 的 random+file 公式补上实际 HMAC(fileFactor, …)，注明 bootstrap 版本由 v1 域字符串及认证元数据绑定；均为规格勘误，不改格式或密码学实现。

## 体验项

| 编号 | 核查判断 | 处理或保留原因 |
| --- | --- | --- |
| U1 | 确认文件往返清空载文，但清除是已批准导航设计；原提醒漏项 | 明确清除全部草稿，要求先选文件、返回后重新导入载文及独立密文的 cover；缺文件时给相同引导。按本次确认不保留载文 |

| U3 | 已知功能限制，非随机数/加密缺陷 | 显示手动转录及长密钥分发困难的提示，推荐跨设备用口令或密钥文件。导出、二维码、凭据存储均不在已批准 v1 范围 |

| U6 | 预览清除秘密、凭据和文件因子符合已有设计，按钮说明不足 | 重新编辑前确认，明确结果清除及必须重填的项目。不得从结果偷偷恢复明文或延长旧结果生命周期 |
| U7 | 序号难辨属实；认证前显示标签不符合索引边界 | 选项追加独立索引已有的更新时间，不额外解密标签/正文。分类标签、认证后预览需另行产品设计，本轮不增加存储数据或正文读取 |
| U8 | 确认死入口，并补交接时全局关闭的拒绝 | 私有粘贴来源和直接读取按钮同时检查全局安全剪贴板开关；没有可用来源就不显示粘贴动作。独立交接也拒绝全局关闭后才到达的旧读取结果 |
| U9 | 确认路径过深 | 选区导入直接位于待解密文本附近，仅在有外部编辑器的解密编辑状态显示；不自动读取 |
| U10 | 确认反馈滞留 | 新输入、候选动作和编辑操作清旧 notice；新的失败可重新发布 |
| U11 | 确认文案过泛 | 专门长度文案，说明秘密 UTF-8 字节上限和公开/载文预算 |

| U13 | 确认公开文本无障碍缺口及长按入口局限 | 仅公开 cover 允许辅助功能读取；增加当前字段的可见粘贴按钮。秘密、凭据、载文正文继续不向无障碍文本节点公开 |
| U14 | 视觉语义优化项 | 模式标签简化为加密/解密，沿用已有选中态 |

| U17 | 确认状态通知缺口 | 状态使用 polite accessibility live region；不公开秘密正文 |
| U18 | 确认初始文案像报错 | 初始显示中性可用范围，只在无效提交时设置错误 |

| U20 | 立即清除是设计，提醒不足 | 页面常规说明列出离开、外部光标变化和超时清除；显式关闭反馈已清除。返回/面板切换继续立即撤销，不插入可能拖延撤销的对话框 |
