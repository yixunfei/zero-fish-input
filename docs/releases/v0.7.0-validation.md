# v0.7.0 release validation

Date: 2026-10-24. Public artifacts: Debug-signed testing prerelease. Release APKs are unsigned validation outputs.

## Checks

- `./gradlew.bat test privacyCheck :app:lintDebug --no-parallel -PrequireRime=true`
- `./tools/package-test-apk.ps1 -Abi arm64-v8a`
- `./tools/package-test-apk.ps1 -Abi armeabi-v7a`
- `./tools/package-test-apk.ps1 -Abi x86_64`
- `tools/check-apk-installable.ps1` for all three ABI APKs
- Android API 36 x86_64 emulator `pm install` without `-t` for the x86_64 APK

All three ABI APKs passed signature, package, minimum API, native ABI and final Manifest checks. The final Manifest does not contain `android:testOnly="true"`; the x86_64 package installed without the ADB test-only flag. The release APKs remain unsigned because no production signing key is stored in the repository.
