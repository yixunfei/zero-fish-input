# zero fish input v0.7.7

Debug 签名测试预发布，包名 `dev.zeroinput.ime.debug`，versionCode `14`。通用 APK 支持 Android 8.0 及以上，包含 `arm64-v8a`、`armeabi-v7a` 和 `x86_64`。

- 新增本地隐写工作区：同页编辑公开文本、秘密正文和凭据，六种算法按选择顺序组合；加密并自检后自动填入原输入框，不自动发送。也可仅生成预览。
- 隐写结果支持秘密正文、公开文本、独立密文及完整结果四类认证私密保存；解密结果默认隐藏，插入与保存分别确认。
- 公开文本和待解密文本长按可主动粘贴一个系统纯文本条目，或认证后从安全剪贴板读取。随机主密钥支持 256/512/1024/4096 位及字节对齐的自定义长度；算法子密钥保持各自支持的位数，不代表等量安全强度。
- 私密临时输入默认遮盖全部已确认文字，主动显示全文后才可查看；隐写页支持滚动编辑和固定主操作区。
- 修复个人化异步刷新撤销模型排序的问题，保留模型候选及其提交路径；新个人词频优先级仍可取代模型排序。
- 设备代理未配置动作类别时默认全部未授权，包含读屏；已有明确保存的类别保持不变。加固滑动坐标和聊天历史索引边界。
- 完善引擎预热、异步生命周期、中文候选分页、语言包 JSON 校验和 AI 连接取消处理。

隐写正文、凭据与载体只在本机处理。系统粘贴仅在明确点击时读取一个有界纯文本条目，不后台监听或自动收录。凭据不保存，丢失后无法恢复；隐写可被检测，也可能被目标应用改写或移除。

下载后请用同页 `SHA256SUMS.txt` 核对文件。第三方许可证和手写模型对应源码随包提供。此版本为 Debug 签名测试预发布，正式 Release 构建仍未签名。
