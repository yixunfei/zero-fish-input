# zero fish input v0.7.5

Debug 签名测试预发布，包名 `dev.zeroinput.ime.debug`，versionCode `12`。通用 APK 支持 Android 8.0 及以上，包含 `arm64-v8a`、`armeabi-v7a` 和 `x86_64`。

- 硬件键盘输入可进入 AI 草稿和表情搜索。编辑器拒绝个人词组或颜文字时，保留组字以便重试。
- 修复降级拼音误转换数字、英文长词丢键和中文末页候选消失。微软双拼含分号的输入可重新转换。
- 用户词组导入和导出的文件选择结果可在设置页重建后返回。搜索词变化时立即重置分页。
- 词库和资源安装在写入确认后才报告成功。语言包安装中断后可回收暂存数据，必要时恢复旧版本。
- 熄屏会撤销已经确认、仍在处理中的安全粘贴。改进 AI 流式输出解析、无障碍按键及管理对话框的稳定性。

下载后可使用同页的 `SHA256SUMS.txt` 核对文件。第三方许可证和手写模型对应源码随包提供。
