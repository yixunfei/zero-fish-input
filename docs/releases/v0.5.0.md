# zero fish input v0.5.0

Android 离线输入法 Debug 签名测试预发布。本版在保持核心输入、个人数据和安全剪贴板离线可用的基础上，完成了新一轮输入状态、词库管理和可选 AI 工作台的审查。

## 下载

- `zero-fish-input-0.5.0-debug-universal.apk`：完整资源包，包含 arm64-v8a、armeabi-v7a 和 x86_64。
- `zero-fish-input-0.5.0-debug-universal-lite.apk`：轻量资源包，保留离线核心词表，其他公开资源可在设置中按需下载。
- 每个 APK 旁附带 `.sha256` 校验文件。

APK 使用 Debug 签名且可调试，版本名 `0.5.0-debug`、versionCode `5`，包名为 `dev.zeroinput.ime.debug`。Release 构建仍保持未签名，尚不是生产签名版本。

## 本版变化

- AI 工作台支持 Chat Completions、Responses 和 Anthropic Messages 三种显式协议，严格校验路由、流式终止事件、输出类型和模型能力。
- 词库管理支持本地词条新增、编辑、删除、撤销和名称修改；修改以独立加密覆盖层保存，不写入公开词典或 Rime 用户词典。
- 拼音组合支持候选栏光标、范围编辑、分词和连续候选浏览，过期会话与异步查询会被代次校验丢弃。
- full/lite 公开资源包共享固定哈希校验和离线核心，轻量包可在设置中按需安装公开资源。
- 补充 AI 协议、词库编辑、候选滚动、拼音光标和资源包内容的回归测试。

## 验证与限制

发布级构建、`privacyCheck`、Debug Lint、JVM 测试、真实 Rime 三 ABI 构建以及 full/lite 包内容和 SHA-256 校验见 [v0.5.0 发布验证](v0.5.0-validation.md)。本版仍需要物理 ARM 设备、厂商编辑器、真实生物识别/设备凭据和真实 AI 服务的单独验收；测试 APK 不应保存真实秘密。
