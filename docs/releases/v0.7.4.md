# zero fish input v0.7.4

Debug 签名测试预发布，包名 `dev.zeroinput.ime.debug`，versionCode `11`。通用 APK 支持 Android 8.0 及以上，包含 `arm64-v8a`、`armeabi-v7a` 和 `x86_64`。

- QQ 和搜狗词库在首页和分类页直接显示可下载项。「分类、排序与来源分页」保留来源导航。点选词库后可确认下载并导入。
- 一级键盘工具栏提供近似字输入。复制选区移到「更多」首位，系统认证后可回到原输入框的键盘内确认保存。
- 修正薄荷绿和樱花粉的候选高亮，更新深色配色，加入可预览的 RGB 背景色选择。
- 设置按用途分组，外观支持样式预设，AI 等独立草稿可移动光标并在中间编辑。
- 修复中文显式选词的个人词频排序。关闭预测建议的普通文本框仍可使用符合隐私策略的中文个性化转换。

本版使用上一版已校验的万象词库与语法模型。近期审核更新引用的上游模型文件已下线，且对应可选下载包尚未发布。

下载后请使用同页的 `SHA256SUMS.txt` 核对文件。第三方许可证和手写模型对应源码随包提供。
