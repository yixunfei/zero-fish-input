# zero finish input v0.1.0

首个开源预发布版本，面向功能体验和测试反馈。源码采用 Apache-2.0，第三方组件及词典数据
保留各自许可证。发布页：<https://github.com/yixunfei/zero-fish-input/releases/tag/v0.1.0>。

## 下载

- `zero-finish-input-0.1.0-debug-universal.apk`：Android 8.0+ 通用测试安装包，包含
  arm64-v8a、armeabi-v7a、x86_64 和真实 librime 1.13.1。
- `zero-finish-input-0.1.0-debug-notices.zip`：许可原文、第三方声明与源码获取说明。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验清单。
- GitHub 自动生成的源码归档对应 `v0.1.0` tag。

APK 为 **Debug 签名且可调试**，版本名 `0.1.0-debug`，包名 `dev.zeroinput.ime.debug`。
它是可安装的测试版，不是正式生产签名产物。Release 构建保持未签名，仓库不包含发布私钥。
请使用公开样例测试，暂勿用此包保存真实秘密；卸载或清除数据会丢失本地加密内容。

## 本版内容

- 中文 Rime 全拼、简拼、简繁切换、独立模糊音设置、全键盘与九键输入。
- 离线英文候选、emoji 分类与中英文搜索、本地最近使用。
- 加密个人词组与词频，用户词组 JSON 导入导出。
- 默认关闭、每次访问需要系统认证的私有安全剪贴板。
- 未知和敏感编辑器保守处理，会话变化与隐私收紧使旧任务失效。
- 词组容量、严格导入、清除竞态及写入失败保护，导出前提示明文风险。
- 新显示名称和基于 `logo.jpg` 的启动图标；完善安装、构建、贡献及许可说明。

## 验证边界

首发检查包括 JVM 单元测试、privacyCheck、Android Lint、真实 Rime 三种 ABI 打包、
未签名 Release 构建和 x86_64 模拟器设备回归。具体结果记录于
[发布验证记录](../release-validation.md)。

ARM 真机运行、厂商输入框和真实生物识别/设备凭据交互尚未完成全面验收。
离线词典测试引擎仅约 130 条词条，不支持整句、简繁、简拼、模糊音或九键。
项目不提供云同步、语音输入或安全片段导出。完整能力和安装步骤见 [README](../../README.md)。
