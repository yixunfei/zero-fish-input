# zero fish input v0.3.0

Android 离线输入法测试预发布。此版本修复中文引擎就绪判断和禁止预测输入框中的中文选词，
增加醒目的准备进度提示，纳入离线词联想及安全存储可靠性改进，并统一修正项目名称。

## 下载与安装

- `zero-fish-input-0.3.0-debug-universal.apk`：Android 8.0+ 通用测试包，包含 arm64-v8a、
  armeabi-v7a 和 x86_64，使用真实 librime 及离线 Mini INT8 模型。
- `zero-fish-input-0.3.0-debug-notices.zip`：项目与第三方许可、声明及源码获取说明。
- `SHA256SUMS.txt`：APK 和许可包的 SHA-256 校验清单。

APK 使用 **Debug 签名且可调试**，版本名 `0.3.0-debug`、versionCode `3`，
包名 `dev.zeroinput.ime.debug`。这仍是测试预发布，尚不是生产签名产物。
签名已核对与 v0.2.0 发布包一致，可保留数据覆盖安装，无需先卸载。
安装签名不匹配时请勿直接卸载，卸载或清除数据会丢失本地加密内容。

## 本版变化

- Rime 初始化和会话准备必须通过公开拼音输入、候选和上屏探针，避免仅创建会话就误报就绪。
- 准备期间持续显示醒目进度，首次尝试中文输入时提醒一次；基础词表仍可使用，失败可重试。
- `NO_SUGGESTIONS` 保留非敏感输入框中的中文转换，关闭英文预测，继续禁止个人数据读取与学习。
- 默认开启的离线词联想使用 1,698 组自编公开词对，支持中英文连续点选；无匹配不显示，
  不读取输入框原文或私人历史，敏感场景禁用。
- 完善候选浏览和表情拼音搜索，减少输入热路径分配、重复设置读取和颜色解析。
- 纳入键盘私有复制、认证后返回确认粘贴和剪贴板防护修复，取消过期会话的迟到操作。
- 强化加密文件提交、密钥失效、内容库清除失败及并发删除处理，并补充负向回归。
- 应用名称、输入法名称和发布文件名统一为 **zero fish input**，仓库地址同步更新。

## 验证与限制

构建、测试和产物核对见 [v0.3.0 发布验证](https://github.com/yixunfei/zero-fish-input/blob/v0.3.0/docs/releases/v0.3.0-validation.md)。
464 次单元测试通过；最终通用 APK 的设备回归及补跑共覆盖 171 项不同用例，均通过。
另有 2 项需要专用测试 PIN 的认证流程未运行。隐私检查、Lint、三种 ABI 的 Debug 和未签名
Release 构建、签名与许可核对通过。
应用继续完全离线，不新增运行时联网权限，不改变持久化数据格式。

本版不承诺缩短首次词典部署时间；准备期间的基础词表覆盖有限。
简拼与词组质量仍需继续改进。公开词对和固定样例评估不代表真实人群输入准确率。
短词智能排序仍是默认关闭的实验，既有模型误改率限制仍然适用。
ARM 真机、厂商输入框、真实生物识别/设备凭据交互及长时间压力测试仍需扩大验收。
iQOO 等系统或其他输入法保存的独立剪贴板历史仍不能由本应用删除。
