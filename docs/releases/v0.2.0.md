# zero finish input v0.2.0

Android 离线输入法测试预发布，改进中文候选浏览与编辑，并修复 Android 16 剪贴板设备回归的
启动和选字菜单问题。发布页：<https://github.com/yixunfei/zero-fish-input/releases/tag/v0.2.0>。

## 下载与安装

- `zero-finish-input-0.2.0-debug-universal.apk`：Android 8.0+ 通用测试包，包含
  arm64-v8a、armeabi-v7a、x86_64、真实 librime 1.13.1 及离线 Mini INT8 模型。
- `zero-finish-input-0.2.0-debug-notices.zip`：项目与第三方许可原文、声明及源码获取说明。
- `SHA256SUMS.txt`：上述两个文件的 SHA-256 校验清单。
- GitHub 自动生成的源码归档对应 `v0.2.0` tag；模型构建资产需按
  [模型构建说明](../model-integration.md#reproduce-assets-and-build)准备。

APK 大小为 122,620,993 字节（约 117 MiB），SHA-256：

```text
687306c94dc110858034ef83afa0b7dc7d8c8f59e5055ed75b25c19042de84dd
```

APK 使用 **Debug 签名且可调试**，版本名 `0.2.0-debug`、versionCode `2`，

## 本版变化

- 连续候选浏览、逐段选字、撤销选段及上屏后重选上一词；候选耗尽后停止扩展。
- 默认关闭的拼音防误触纠错，以及标有“相近”的分组和相关读音候选。
- 默认关闭的短词智能排序实验：Mini INT8 只使用当前会话中由本输入法成功上屏的有限中文
  上下文，离线调整合适的两字词候选；敏感输入不提供模型上下文。
- 扩充表情与颜文字搜索、分类、加密收藏及自定义管理；增加键盘主题、按键高度和紧凑横屏布局。
- 安全剪贴板支持原生选字菜单与文本分享后的认证导入；独立系统剪贴板防护仍默认关闭，
  仅使用元信息，支持用户配置通用提醒和确认清理。
- 修复 Android 16 测试中输入法尚未绑定引发的确认页超时，以及状态栏遮挡测试文字导致的
  原生选字菜单不稳定；增加取消确认、关闭监听及服务未绑定时的负向回归。
- 更新 README、模型准备流程、第三方声明、安全边界和验证记录。

## 验证与已知限制

本次构建、设备测试、产物和签名核对结果见 [v0.2.0 发布验证](v0.2.0-validation.md)。
334 次 JVM 测试和新通用包上的 131 项 Android 16 设备测试全部通过，零失败、零跳过；
隐私检查、Lint、真实 Rime 三种 ABI Debug/未签名 Release 构建及包内资源校验通过。
剪贴板修复的复现与重复测试记录见 [模型与剪贴板验证](../model-integration-validation.md)。

模型原定误改率门槛未通过：94 条构造的保留样例中，首选正确数从 36 增至 47，同时误改一条
原本正确的首选。因此排序仍为默认关闭的实验，不能据此宣称真实人群准确率或主流输入法水平。
约 15 MB 模型与词表不包含 ONNX 运行库；通用包大小明显增加。

ARM 真机性能、电量、长时间内存压力、厂商输入框和真实生物识别/设备凭据交互仍需验收。
模拟器通过不代表所有设备通过。应用不联网、不自动上传，不新增用户数据迁移格式。
卸载或清除数据仍会丢失本地加密内容；请勿用此测试包保存真实秘密。
