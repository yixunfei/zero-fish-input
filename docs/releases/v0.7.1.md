# zero fish input v0.7.1

Debug 签名测试预发布，包名 `dev.zeroinput.ime.debug`，versionCode 8。

## 变化

- 符号键盘提供 12 个可直接选择的分组：中文常用、英文常用、数学常用、希腊符号、箭头符号、图标符号、几何图形、单位货币、数字序号、拼音注音、拉丁字母和制表符号。
- 扩充至 1336 个符号条目，各分组独立分页，每页最多 27 个，支持左右滑动与页码按钮连续浏览。
- 保留上一轮中文 Shift 半角标点、私密复制快捷入口、自定义表情删除和词频学习修复。

## 安装

下载 `zero-fish-input-0.7.1-debug-universal.apk`，包含 arm64-v8a、armeabi-v7a、x86_64。
同签名测试版可覆盖升级；签名冲突时不要直接卸载，以免丢失本地数据。
使用 `SHA256SUMS.txt` 验证下载，许可及对应源码随包提供。

这是可调试的测试版本，尚未配置正式发布签名。ARM 真机、厂商字体和真实社交软件验收仍需单独进行。
完整验证见 [验证记录](v0.7.1-validation.md)。
