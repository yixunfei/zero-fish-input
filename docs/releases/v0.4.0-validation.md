# v0.4.0 release validation

Date: 2026-09-28. Public artifact: Debug-signed testing prerelease.

## Checks

- `./gradlew.bat check privacyCheck :app:assembleDebug :app:assembleRelease -PrequireRime=true --no-parallel`
- `./tools/package-test-apk.ps1` with full checks and the pinned Rime sources.
- Debug and unsigned Release merged manifests: approved permissions only, backup disabled, cleartext traffic disabled, Release not debuggable.
- Debug universal APK metadata, signature and native ABI set: arm64-v8a, armeabi-v7a and x86_64.

The final JVM/Android module tests, privacy boundary checks, module Lint and Rime native builds passed. The selected device regressions from the audit passed 59 tests on the Android 36 x86_64 emulator and cover authentication delivery, private clipboard privacy, AI parsing/settings, editor deletion, reconversion, language-pack installation, encrypted storage, keyboard interaction and nine-key input. The focused fixture rerun verified the updated status, toolbar, emoji navigation and fullscreen sizing contracts, including the inset-aware rotation fix. One legacy rapid-burst reconversion assertion remains device-sensitive and is retained as follow-up coverage rather than a release blocker; the controller-level reconversion and negative-path tests pass.

## Published artifact boundaries

The public APK is Debug signed and intended for testing only. No production signing key is generated or included. Release APKs are unsigned validation outputs and are not public installable artifacts. Physical ARM devices, vendor editors, hardware biometric/device-credential flows, long-running power-loss behavior and real AI provider interoperability remain outside this validation run.
