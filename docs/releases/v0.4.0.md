# zero fish input v0.4.0

Android 离线输入法 Debug 签名测试预发布。此版本在保持核心输入、个性化、表情和安全剪贴板离线可用的基础上，加入默认关闭的可选联网 AI 工作台，并完成一轮发布前安全与稳定性审查。

## 下载与安装

- `zero-fish-input-0.4.0-debug-universal.apk`：Android 8.0+ 通用测试包，包含 arm64-v8a、armeabi-v7a 和 x86_64。
- `zero-fish-input-0.4.0-debug-notices.zip`：项目与第三方许可、声明及源码获取说明。
- `SHA256SUMS.txt`：APK 和许可包的 SHA-256 校验清单。

APK 使用 Debug 签名且可调试，版本名 `0.4.0-debug`、versionCode `4`，包名
`dev.zeroinput.ime.debug`。这不是生产签名版本；Release 构建仅作为未签名校验产物。

## 本版变化

- 新增默认关闭的 AI 工作台：只有用户同时开启 AI 与联网开关并主动提交工作台草稿时才发送 HTTPS 请求。
- AI 流式响应拒绝截断、过滤、工具调用、非字符串正文和空结果；请求、历史、超时和响应大小均有限制。
- 修复认证成功已排队时取消仍可能授予权限的竞态，强化私有剪贴板管理弹窗的截屏、状态保存和草稿清理保护。
- 修复中文部分选字回退、九键长度边界、候选排序调度失败、语言包递归 JSON 边界和替换回滚问题。
- 修复 AI 设置保存失败覆盖旧配置、会话标题截断代理字符、学习词频溢出和非法 Unicode 持久化问题。
- 补充输入诊断、候选显示、设置异步失败和语言包安装的回归覆盖；不改变持久化数据格式、密钥别名或权限边界。

## 验证与限制

完整构建、隐私检查、Lint、真实 Rime 三 ABI 构建及审计回归见
[v0.4.0 发布验证](v0.4.0-validation.md)。APK 仅用于测试；正式签名、物理 ARM/OEM 设备、真实生物识别流程和真实 AI 服务互操作性仍需单独验收。
