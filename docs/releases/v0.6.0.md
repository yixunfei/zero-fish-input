# zero fish input v0.6.0

Android 离线输入法 Debug 签名测试预发布。本版在保持核心输入、个人数据和安全剪贴板离线可用的基础上，完成了新一轮代码审查处置、AI 工作台稳定性修复、中文草稿转换修复和输入候选连续性修复。

## 下载

- `zero-fish-input-0.6.0-debug-universal.apk`：完整资源包，包含 `arm64-v8a`、`armeabi-v7a` 和 `x86_64`。
- `zero-fish-input-0.6.0-debug-universal-lite.apk`：轻量资源包，保留离线核心词表，其他公开资源可在设置中按需下载。
- `SHA256SUMS.txt`：测试 APK、许可证和对应源码归档的 SHA-256 清单。

APK 使用 Debug 签名且可调试，版本名 `0.6.0-debug`、versionCode `6`，包名为 `dev.zeroinput.ime.debug`。Release 构建仍保持未签名，尚不是生产签名版本。

## 主要变化

- AI 工作台的多协议解析、流式终止、响应结构和容量错误处理更严格，过期会话、隐私收紧、停止生成和保存失败不会留下可插入的旧结果。
- AI 草稿保留当前中文输入编码，中文引擎后台就绪后继续转换拼音；引擎失败时显示受控失败状态并提供重试。
- 拼音组合支持候选栏光标、范围编辑、分词和连续候选浏览，异步查询以会话和数据代次校验，旧结果不会提交到新编辑器。
- 词库、语言包、安全剪贴板、加密存储和设置清除流程补充容量、损坏、回滚、密钥失败和并发负向测试。
- 继续保持 AI 联网默认关闭、系统剪贴板正文不可读、备份关闭、Release 不可调试和语言包只允许数据文件的边界。

## 验证

发布级构建、`privacyCheck`、Debug Lint、JVM 测试、真实 Rime 三 ABI 构建以及 APK 内容和 SHA-256 校验见 [v0.6.0 发布验证](v0.6.0-validation.md)。本版仍需要物理 ARM 设备、厂商编辑器、真实生物识别/设备凭据和真实 AI 服务的单独验收；测试 APK 不应保存真实秘密。
