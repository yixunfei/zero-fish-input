# v0.7.7 validation

Date: 2026-11-19. Public distribution is a Debug-signed testing prerelease,
application ID `dev.zeroinput.ime.debug`, version `0.7.7-debug`, version code 14.
The universal APK contains arm64-v8a, armeabi-v7a and x86_64 and supports API 26+.
Production Release splits remain unsigned and are not distribution assets.

## Scope

This release includes the local steganography workspace and its November 18-19
usability, paste, credential and lifecycle repairs, full private-draft masking,
and the verified audit corrections. See
[steganography acceptance](../text-steganography-validation.md),
[the refactor recheck](../audits/2026-11-18-refactor-recheck.md) and
[the full-review verification](../audits/2026-11-19-full-code-review-fixes.md).

The full-review corrections default missing agent categories to none while
retaining explicit grants, preserve a valid model winner across personal-data
refresh without overriding personal priority, and harden swipe parsing and
incomplete history appends. Six other static-review findings were not supported
by the present contracts or reproduction probes. README now describes the
shipped functionality, full masking and variable random-master-material lengths.

## Build and automated checks

Successful root commands:

```powershell
./gradlew.bat test privacyCheck :app:lintDebug :app:lintRelease `
  :app:assembleRelease :app:assembleDebugAndroidTest `
  -PrequireRime=true --no-parallel --max-workers=4
python -m unittest discover -s tools/resources -p 'test_*.py'
python -m unittest discover -s tools/dictionaries -p 'test_*.py'
./tools/test-test-apk-artifact.ps1
./tools/test-instrumentation-result.ps1
./tools/test-jni-failures.ps1 -SdkRoot D:/env/AndroidSDK -Serial emulator-5580
./tools/package-test-apk.ps1 -Abi universal -MaxApkBytes 180000000 -SkipChecks `
  -OutputDirectory app/build/outputs/test-apk-v0.7.7
```

`-SkipChecks` reused the immediately preceding full test/privacy/Debug+Release
Lint run. APK contents, installability, signature, size, native ABI and permission
checks still ran. No gate was weakened. Both lint reports say `No issues found`.
Source privacy checks, negative checker tests and Debug/Release merged manifests
passed. Backup remains disabled, the stego source is nonexported, and Release
is not debuggable.

Across 12 modules and Debug/Release variants: **2,236 unit passes, four opt-in
live-provider skips, zero failures/errors**. These represent 1,165 distinct
cases: 1,163 passed, two skipped. Reused results and repeated variants are not
new distinct cases. Resource tooling passed 16 tests and dictionary tooling 18;
packaging locator/reset and instrumentation-result parser checks passed.
JNI failure injection passed on the isolated x86_64 emulator.

All three native ABIs built for Debug and Release with real Rime required.
Each unsigned Release split passed full dictionary/model/native verification,
ELF architecture checks and comparison of all 32 bundled license/notice files.
The universal Debug APK and notices archive contain the same 32 exact files.
Pinned handwriting corresponding sources were packaged and checksummed.

## Upgrade and device acceptance

The official v0.7.6 universal APK was downloaded and its SHA-256 verified against
both public release metadata and the previous validation record:
`a8ad033834c462f2515970e847a4e360ea5258cc81939a620fd207cb356e2684`.
The isolated API 37 x86_64 emulator installed it, then upgraded in place to the
exact packaged v0.7.7 universal APK. Version code advanced from 13 to 14.
Both APK certificates have SHA-256:
`d66972b598062015bc4092c1e45e05d8b4b437d6a1be8069e07907c1a97c14d6`.

The installed distribution APK passed all **36 stego tests**, with zero skips.
Coverage includes six-layer crypto/self-check, automatic insertion, four-output
save/read authentication, explicit confirmation, editor return, generation and
replay rejection, cancellation, settings/deletion revocation, credential bounds,
queue failures, worker buffer cleanup and scrollable control reachability.
Two system-paste cases independently passed with zero skips, covering explicit
source-menu touch and text/URI/Intent/multiple-item/size/Unicode/revocation rules.

The separate core regression run passed all **65 tests**, with zero skips or
failures. It covers the audit boundary cases and actual category-settings page,
candidate scrolling/window continuity/reset, local-draft caret, handwriting,
full private-draft masking, native engine contracts/pinyin, bounded language-pack
JSON, vault reliability, AI settings failure, engine preparation and composition
editing. Together these successful runs cover **103 distinct platform cases**.

Both attached layout probes passed again at 240x480, dark theme and 1.3 font scale,
and at 640x320, light theme and 1.0 font scale: four additional repeated executions,
not four new distinct cases. Screenshots were inspected; primary actions remain
visible and the bounded editor scrolls to the remaining controls.

One initial regression command specified the wrong package for
`AiSettingsFailureTest` and correctly failed initialization; the command was
corrected. A later combined run passed 66 of 67 cases, with one source-menu touch
timing out after an extended UI sequence. The identical source-menu case passed
in the earlier sequence and both system-paste cases passed in their isolated
recheck. Production code and assertions were not changed. These unsuccessful
combined logs are retained as timing/reproduction evidence and are not reported
as passing runs.

After acceptance, installed main/test APK hashes matched their exact local build
artifacts. The final main APK hash remains the distribution hash below. The
temporary test PIN was cleared successfully; original IME, display size/density,
font, rotation and night mode were restored. The task-owned emulator was stopped.

## Limits

No physical ARM/OEM or older Android runtime was tested. Live external AI/MCP
interoperability and real third-party stego-message retention were not tested.
Build success does not establish runtime behavior on those devices or channels.
The intermittent menu-touch test timing noted above remains an acceptance-harness
limitation. No production signing key was created or used. No signed production
Release is offered.
