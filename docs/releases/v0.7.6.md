# zero fish input v0.7.6

Debug 签名测试预发布，包名 `dev.zeroinput.ime.debug`，versionCode `13`。通用 APK 支持 Android 8.0 及以上，包含 `arm64-v8a`、`armeabi-v7a` 和 `x86_64`。

- 修复重复加载相同 AI 设置可能误取消已排队请求的问题。主动修改设置、关闭联网或清除数据仍会撤销旧请求。
- 修复 AI 设置保存失败后的恢复逻辑，防止用空配置覆盖已有服务商。恢复编辑时 AI 与联网开关保持关闭，需要明确保存后才能重新启用。
- AI 应用级快照不再保留明文密钥，请求时才在后台读取所选凭据。离开设置页会清除未保存的服务商草稿。
- 完善原生中文引擎的异常边界和资源释放，避免分配失败时继续执行 JNI 调用。
- 限制语言包文本单行长度和字段数，降低异常文件造成内存耗尽的风险。
- 修正 Android 8 系统剪贴板空项识别和语言键长按提示，并补齐第三方许可及跨引擎契约检查。
- 打包时逐个 ABI 校验 Rime、C++ 运行库和 ONNX 库，避免缺少原生库的通用包通过检查。

下载后可使用同页的 `SHA256SUMS.txt` 核对文件。第三方许可证和手写模型对应源码随包提供。此版本是测试预发布，正式 Release 构建仍未签名。
