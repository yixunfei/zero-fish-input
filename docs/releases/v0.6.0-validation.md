# v0.6.0 release validation

Date: 2026-10-19. Public artifacts: Debug-signed testing prerelease. Release APKs are unsigned validation outputs.

## Commands

- `./gradlew.bat :app:assembleDebug testDebugUnitTest privacyCheck :app:lintDebug -PrequireRime=true '-Pandroid.injected.build.abi=x86_64' --no-parallel`
- `./gradlew.bat :app:assembleRelease -PrequireRime=true -PresourceBundle=full --no-parallel`
- `./gradlew.bat :app:clean :app:assembleDebug -PrequireRime=true -PresourceBundle=lite -PtestUniversalApk=true --no-parallel`
- `./tools/package-test-apk.ps1 -Abi universal -OutputDirectory build/outputs/test-apk-v0.6.0`
- `python tools/resources/verify-apk.py full <each release APK>` and `python tools/resources/verify-apk.py lite <lite Debug APK>`

All listed Gradle commands passed. The package script passed its unit tests, `privacyCheck`, Debug Lint, real Rime builds for `arm64-v8a`, `armeabi-v7a` and `x86_64`, and Debug APK package, ABI, permission and signature checks. Full and lite APK content checks passed, including pinned dictionary hashes, ONNX runtime hashes, resource bundle contents and the complete Emoji artwork set.
