# zero fish input v0.7.3

Debug 签名测试预发布，包名 `dev.zeroinput.ime.debug`，versionCode `10`。通用 APK 支持 Android 8.0 及以上，包含 `arm64-v8a`、`armeabi-v7a` 和 `x86_64`。

## 私密输入

- 在键盘副框内输入。当前拼音、候选和最近三个已输入的字保持可见，可用「本次明文」查看当前草稿。
- 「保存并关闭」把内容加密存入安全剪贴板。「保存并提交」还会插入当前输入框，可在隐私设置中关闭副本。「仅提交」直接插入当前输入框。
- 默认关闭，启用或停用需身份认证。启用后，符合条件的文本输入框自动打开副框。私密粘贴仍需单独认证和确认。

## 同型字与工具栏

- 可直接选部首，也可用拼音找近似字。根据共享部件和结构排列离线匹配，候选带拼音，支持连续滑动和点选插入。
- 私密临时输入和安全剪贴板可从一级工具栏打开。私密复制改用图标。展开更多工具时，额外选项排在一级常用项前面。

## 公共词库

- 修复 QQ 和搜狗词库的下载与导入，区分导入与打开来源网站，并过滤超过下载上限的 GitHub 文件。

下载通用 APK 后，使用同页的 `SHA256SUMS.txt` 核对文件。第三方许可证和手写模型对应源码随包提供。
