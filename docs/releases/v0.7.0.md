# zero fish input v0.7.0

Android 离线输入法 Debug 签名测试预发布。本版在保持核心输入、个人数据和安全剪贴板离线可用的基础上，完善了个人联想学习、AI 工作台稳定性和测试包安装流程。

## 下载

- `zero-fish-input-0.7.0-debug-universal.apk`：完整资源包，包含 `arm64-v8a`、`armeabi-v7a` 和 `x86_64`。
- `zero-fish-input-0.7.0-debug-universal-lite.apk`：轻量资源包，保留离线核心词表，其他公开资源可在设置中按需下载。
- `SHA256SUMS.txt`：测试 APK、许可证和对应源码归档的 SHA-256 清单。

APK 使用 Debug 签名且可调试，版本名 `0.7.0-debug`、versionCode `7`，包名为 `dev.zeroinput.ime.debug`。Release 构建仍保持未签名，尚不是生产签名版本。

## 主要变化

- 个人候选和后续联想使用输入码维度的动态权重，默认点击候选学习，达到可配置阈值后提升排序，不固定置顶。
- 新增“管理用户联想”，支持拼音、简拼、输入码或词语搜索，分页查看、新增、编辑、删除和权重调整。
- 提交结果学习保持默认关闭，可在设置中显式开启；敏感编辑器和隐私收紧会立即阻断学习与个人读取。
- Debug ABI 测试包关闭 `testOnly` 标记，文件管理器可以直接安装；打包前新增签名、Manifest、最低 API 和 ABI 检查。
- 延续 AI 工作台、中文输入、语言包、安全剪贴板和设备代理的既有隐私边界。

## 验证

完整验证结果见 [v0.7.0 发布验证](v0.7.0-validation.md)。测试 APK 仅用于体验和反馈，不应保存真实秘密；正式 ARM 设备和厂商安装器仍需单独验收。
