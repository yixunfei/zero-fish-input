# v0.5.0 release validation

Date: 2026-10-15. Public artifacts: Debug-signed testing prerelease. Release APKs are unsigned validation outputs.

## Checks

- `./gradlew.bat testDebugUnitTest privacyCheck :app:lintDebug --no-parallel`
- `./gradlew.bat :app:assembleRelease -PrequireRime=true -PresourceBundle=full --no-parallel`
- `./gradlew.bat :app:clean :app:assembleRelease -PrequireRime=true -PresourceBundle=lite --no-parallel`
- `./gradlew.bat :app:clean :app:assembleDebug -PrequireRime=true -PresourceBundle=full -PtestUniversalApk=true --no-parallel`
- `./gradlew.bat :app:clean :app:assembleDebug -PrequireRime=true -PresourceBundle=lite -PtestUniversalApk=true --no-parallel`
- `tools/resources/verify-apk.py` passed for all three Release ABIs in both bundles and for both Debug universal APKs.
- `aapt2 dump badging` confirmed `dev.zeroinput.ime.debug`, `versionCode=5`, `versionName=0.5.0-debug`, and the `zero fish input` label.

The JVM tests, privacy boundary, Debug Lint, real Rime native builds, Release R8/Lint, and full/lite APK content checks passed. The audit did not identify a release-blocking correctness, privacy, lifecycle, or input-thread I/O defect in the current tree.

## Remaining validation limits

Physical ARM devices, vendor-specific editors, hardware biometric/device-credential flows, long-running power-loss behavior, and live AI provider interoperability still require separate validation. The unsigned Release APKs are not public installable artifacts.
