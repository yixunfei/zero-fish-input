# zero fish input v0.7.2

Debug 签名测试预发布，包名 `dev.zeroinput.ime.debug`，versionCode `9`。通用 APK 支持 Android 8.0 及以上，包含 arm64-v8a、armeabi-v7a 和 x86_64。

## 输入体验

- `nmen` 可选“你们”。`nmeng` 的首屏同时提供“柠檬”和“你们”，原拼写匹配优先。
- 符号首页提供 27 个常用符号，支持左右按钮和滑动翻页，`123` 可直达数字键盘。
- 成对符号默认自动补全，光标放在中间。可在「设置 → 输入 → 成对符号自动补全」关闭。
- 改进全拼候选排序、个人词频管理、词联想和本地词库管理反馈。

## 可选 AI 功能

- 新增独立桌面入口、角色和显式记忆、声明式 Skill 与手动会话压缩。
- 增加需用户显式启用的文件工具、远程工具连接、任务通知和系统助手入口。任务操作和数据发送沿用单独授权与逐次确认。
- 私有虚拟屏预览仅用于固定公开样例。

下载通用 APK 后，使用同页的 `SHA256SUMS.txt` 核对文件。第三方许可证和手写模型对应源码随包提供。
