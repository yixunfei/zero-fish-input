1. **复现基线。** 从 [锁文件](../tools/dictionaries/sources.lock.json)取得诗词表哈希，核对 `engine-rime/build/generated/publicDictionaryAssets/rime/dicts/shici.dict.yaml`。沿用设计第 7 节的取列、汉字范围、去重、码点排序和标点口径。预期五字池 213,300 项，七字池 92,141 项。不限主题的五字池承载 162 B 公共样本需 77 行、462 个字符；含“月”的五字池有 3,942 项，计算值为 118 行、708 个字符。结果不同时先查数据版本和计数口径。
2. **做三组对照。** 用相同的 162、226、290 B 公开载荷和固定测试种子比较自由集句、主题集句、主题加上下句约束。以“月”“山”筛选复现计数，再用公开意象词和可解释的衔接规则建立主题。可复用现有公开词库与联想材料；协议中所有影响候选池的选择都要能由约定的配置和已恢复的上文重建。
3. **验证解码。** 提供可重复运行的主机命令、数据版本及公开测试向量。重新加载资源后独立解码，不共享编码器的候选列表或位游标。记录测试是否事先告知载荷长度；覆盖补位、候选不足、错误配置、截断和改字，区分能在实验码表层发现的错误与必须由消息认证发现的错误。
4. **验证可用性。** 每组报告逐字节一致数/总数、容量不足数、行数、含标点的 UTF-16 与 UTF-8 长度、重复率，以及 512 单元草稿和整条载体上限内各自的成功率。准备去标签、随机排序的公开样本，与同条件普通集句和真实集句作盲评。尚无独立读者评分时，交付样本和评分表，自评不能代替盲评结论。
